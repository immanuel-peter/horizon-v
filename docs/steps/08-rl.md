# Step 8: Stage 2, projector-only GRPO

Start from the SFT checkpoint. Train only the projector with GRPO, using IFM's validated K2-7B settings from RL360 and sweeping only the LR.

## Launch

Adapted from `examples/geo3k_vlm/run_geo3k_vlm.sh` with the FSDP backend. All flags exist in upstream Miles. Run with the project venv active ([step 0](00-environment.md)).

```bash
python third_party/miles/train_async.py \
  --train-backend fsdp --gradient-checkpointing --attn-implementation flash_attention_2 \
  --actor-num-nodes 1 --actor-num-gpus-per-node 2 \
  --rollout-num-gpus 6 --rollout-num-gpus-per-engine 1 \
  --hf-checkpoint /models/K2-Horizon-V-sft --load /models/K2-Horizon-V-sft \

  --custom-rm-path k2hv.reward.score \
  --rollout-shuffle --num-rollout 500 \
  --rollout-batch-size 64 --n-samples-per-prompt 8 --global-batch-size 512 \

  --eps-clip 0.2 --eps-clip-high 0.28 \
  --kl-coef 0 --kl-loss-coef 0 --entropy-coef 0 \
  --optimizer adam --lr 1e-5 --lr-decay-style constant \
  --adam-beta1 0.9 --adam-beta2 0.98 --weight-decay 0.1 \

```

| Setting | Source |
|---|---|
| GRPO without std normalization, TIS, clip 0.2 / 0.28, KL 0, Adam β 0.9 / 0.98, WD 0.1, constant LR | RL360 `recipes/coding-overfit32.sbatch:111-124` |

- **No reference model.** KL is 0, so none is loaded.
- **`--use-tis`.** Truncated importance sampling corrects small residual logprob gaps between HF training and SGLang rollouts ([step 4](04-gate-checks.md), check 6).

## Reward

Vendor RL360's scorers (`src/miles360/reward/`) into `src/k2hv/rl360_reward/` and wrap them so they score only the text after the think block. They take the raw `sample.response`, and stock `--rm-type math` would also match a `\boxed{}` inside the reasoning.

```python
# k2hv/reward.py
import copy
import re

from k2hv.rl360_reward import async_rm

THINK_CLOSE = re.compile(r"</ifm\|think(?:_fast|_faster)?>")


async def score(args, sample, **kwargs):
    parts = THINK_CLOSE.split(sample.response)
    if len(parts) < 2:
        return 0.0
    answer_only = copy.copy(sample)
    answer_only.response = parts[-1]
    return await async_rm(args, answer_only, **kwargs)
```

- A think block that never closes (truncation) scores 0.
- Add the scorers' dependencies with `uv add`. The rest of RL360 is not needed.
- `metadata.data_source` in each row picks the scorer ([step 5](05-data.md)).

## Weight-sync patch

`_iter_hf_param_units` (`miles/backends/fsdp_utils/hf_weight_iterator.py:24`) pushes the full state dict (~16 GB) to SGLang after every step. SGLang's frozen copies already match, so send only trainable weights (~67 MB):

```python
trainable = {n for n, p in self.model.named_parameters() if p.requires_grad}
for name, param in self.model.state_dict().items():
    if name not in trainable:
        continue
    ...
```

SGLang's `load_weights` must accept this projector-only update ([step 3](03-sglang-model.md)).

## GPU split

Training is tiny and generation dominates. On one 8×H100 node, use 2 GPUs for the FSDP trainer and 6 single-GPU SGLang engines instead of colocating.

## Reasoning effort

Measure K2's thinking length on the filtered RL prompts with the SFT checkpoint. If high effort runs past about 4k tokens, switch to `{"reasoning_effort": "medium"}`. That roughly halves rollout cost. Use the same effort for prompt selection, training and eval.

## Monitor

| Metric | Healthy |
|---|---|
| Reward | Rising, then plateau |
| Response length | Stable or slowly rising; a collapse means the projector found a shortcut |
| Train vs rollout logprob gap | Small and flat |
| Think-close rate | Near 100% |
| Step 7 evals, every 20 steps | Above the SFT baseline |

Expect 200–500 steps. Stop when held-out evals plateau, then export with `third_party/miles/tools/convert_fsdp_to_hf.py --origin-hf-dir /models/K2-Horizon-V-sft` ([step 6](06-sft.md)).
